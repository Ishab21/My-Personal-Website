UX CASE STUDY

Work & Whisk is a calming study timer concept that reframes productivity as a ritual. The UX focuses on minimal cognitive load, clear steps, and a gentle reward loop through visual change.

Visit site Jump to Ideation

Problem

Most study timers feel strict and transactional. When users feel stressed, they’re more likely to stop early. I wanted to create a timer that feels comforting and motivating.

Solution

  • Minimal flow: set time → start → focus → reward.
  • Visual matcha transformation to reinforce progress.
  • Calm aesthetic to reduce anxiety while studying.
