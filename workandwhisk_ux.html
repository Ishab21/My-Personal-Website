Problem Statement

Standard study timers can feel cold and transactional. Users often lose motivation because the experience doesn’t reinforce progress emotionally. The goal was to design a timer that feels calming, rewarding, and visually motivating—without becoming distracting.

The Solution

  • Designed a visual reward loop (matcha “whisks” as you focus).
  • Kept one primary action per step to reduce cognitive load.
  • Used calm hierarchy and spacing to support focus.
  • Designed feedback moments (start, mid-way, completion).

STEP 1

User Motivation Insight

Pain point: Timers don’t reinforce progress emotionally.
Insight: A gentle visual reward can increase motivation and reduce stress.
Goal: Keep UI minimal so it supports focus.

STEP 2

Flow + Reward Loop

Core loop: Set duration → Start → Focus → Visual progress → Completion reward.
Constraint: Reward must be calming, not distracting.
UX choice: One primary CTA per step.

Challenges & Learnings

Challenges

  • Reward satisfying but not distracting.
  • Progress “feels real” with minimal UI.
  • Aesthetic design + functional clarity.

What I Learned

  • Emotional design can support habit building.
  • Less UI can create more calm (better focus).
  • Feedback matters as much as the timer.
